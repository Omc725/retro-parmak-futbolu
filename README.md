*   **Üç Farklı Oyun Modu:**

## 📲 PWA Olarak Yükleme (Çevrimdışı Oynama)

Bu oyun, bir **Aşamalı Web Uygulaması (PWA)** olarak tasarlanmıştır. Bu, oyunu bir mağazadan indirmiş gibi cihazınıza kurabileceğiniz ve internet bağlantınız olmasa bile oynayabileceğiniz anlamına gelir.

### PWA Nedir?
PWA, modern web teknolojilerini kullanarak bir web sitesine uygulama benzeri özellikler (çevrimdışı çalışma, ana ekrana ekleme, anlık bildirimler vb.) kazandıran bir yöntemdir.

### Nasıl Yüklenir?

#### 📱 Mobil Cihazlarda (Android/iOS)

1.  Cihazınızın tarayıcısından (Chrome, Safari vb.) oyunun web sitesini ziyaret edin: **[https://omc725.github.io/retro-parmak-futbolu/](https://omc725.github.io/retro-parmak-futbolu/)**
2.  **Android (Chrome):** Adres çubuğunun sağ tarafında çıkan **"Yükle" (Install)** simgesine veya tarayıcı menüsündeki (⋮) **"Uygulamayı Yükle"** seçeneğine dokunun.
3.  **iOS (Safari):** Paylaşım simgesine (↑) dokunun ve açılan menüden **"Ana Ekrana Ekle" (Add to Home Screen)** seçeneğini seçin.

Artık oyun, diğer uygulamalarınızın yanında, ana ekranınızda bir simge olarak görünecektir.

#### 💻 Masaüstünde (Chrome/Edge)

1.  Tarayıcınızdan oyunun web sitesini ziyaret edin.
2.  Adres çubuğunun sağ tarafında, yer imi yıldızının yanında bir **bilgisayar ve indirme oku simgesi** göreceksiniz.
3.  Bu simgeye tıklayın ve ardından **"Yükle" (Install)** butonuna basın.

Oyun, kendi penceresinde açılan bir masaüstü uygulaması olarak yüklenecektir.

## 🚀 Yerel Olarak Çalıştırma (Geliştiriciler İçin)

Bu projeyi kendi bilgisayarınızda geliştirmek veya çalıştırmak isterseniz, aşağıdaki adımları izleyin.

### Gereksinimler
*   [Node.js](https://nodejs.org/) (v18 veya üstü tavsiye edilir)
*   npm (Node.js ile birlikte gelir)

### Kurulum ve Başlatma

1.  **Depoyu klonlayın:**
    ```bash
    git clone https://github.com/Omc725/retro-parmak-futbolu.git
    ```

2.  **Proje dizinine gidin:**
    ```bash
    cd retro-parmak-futbolu
    ```

3.  **Gerekli paketleri yükleyin:**
    ```bash
    npm install
    ```

4.  **Geliştirme sunucusunu başlatın:**
    ```bash
    npm run dev
    ```

5.  Tarayıcınızda `http://localhost:3000` (veya terminalde belirtilen farklı bir port) adresini açın.

### 🛠️ Kullanılabilir Scriptler

*   `npm run dev`: Geliştirme sunucusunu başlatır.
*   `npm run build`: Projeyi `dist` klasörüne yayınlanmaya hazır hale getirir.
*   `npm run deploy`: Projeyi derler ve GitHub Pages'e otomatik olarak yayınlar.
*   `npm run optimize-assets`: `public/assets` klasöründeki resimleri optimize eder, eskilerini siler ve koddaki dosya yollarını günceller.
